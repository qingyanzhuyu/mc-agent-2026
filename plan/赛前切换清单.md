# 赛前切换清单（初赛 11/22）

> 2026-11-14 版 · 依据 `docs/00` 的官方口径 + 本机实测
> **用法**：开赛前按「T-7 / T-1 / T-0」三段执行，每一项都有验证命令；做完打勾。
> 核心原则：**开发期和生产期的配置是两套，绝不共用。**

---

## 0. 一句话说清风险

开发期官方给 **48 路并发**，比赛期**只给 2 路**（甚至可能 1 路）。
所有按 48 路调出来的参数（并发、超时、预取）**在比赛当天会把 Agent 卡死**。

所以这份清单的第一件事不是"加什么"，而是**把开发期的宽松参数收回去**。

## 2. T-1（11/21）：切环境、清现场

### 2.1 必须改的配置（`code/mcagent/.env`）

| 字段 | 开发期现在是什么 | 比赛必须改成 | 改错的后果 |
|---|---|---|---|
| `MC_API_BASE` | `http://127.0.0.1:8787/api/v1`（本地网关） | **`https://apiin.nmo.net.cn/api/v1`**（校园网）或公网端点 | 指向网关 = 用自建客户端打比赛，**违规** |
| `MC_USER` | `qyzy_dev` | **皮肤站里那个角色的名字** | 登不上，或登成别人的号 |
| `MC_PASS` | `localdev` | **皮肤站密码** | 登录失败 |
| `MC_PROXY` | 空 | 空（校园网直连）；若走公网且需要代理再填 | 填了 7897 会把 5ms 变 200ms |
| `LLM_KEY` | 群里的压测 key | **队伍正式 key** | 可能被限流或封 |
| `LLM_MODEL` | `default` | `default`（**不能改**，写模型名会 403） | 直接 403 |
| `LLM_MAX_CONCURRENCY` | 48（压测时） | **2** | 超限被排队/429，决策全部拖慢 |
| `LLM_PROXY_FAST` | `http://127.0.0.1:7897` | 视网络：开思考走直连的那条不受影响，快路径仍可走代理 | —— |

### 2.2 必须停掉的东西

| 项 | 检查方法 | 为什么 |
|---|---|---|
| **本地联调网关** | `curl -s --max-time 2 http://127.0.0.1:8787/healthz` 必须失败 | 它连的是自建协议客户端；留着就有误用的可能，而且它挂在共享测试世界里 |
| **任何跑在这把 key 上的 DSH 会话** | 关掉所有 DSH 窗口 | 每步都是一次 LLM 调用，会吃掉 2 路并发里的一半 |
| **后台长任务**（soak / 挂机脚本） | 检查进程列表 | 同上，且会占着 `MC_USER` 让别人登不上 |
| **`.token.json` 里的旧 token** | 文件存在但 base 变了 → 首次调用 401 会自动重登，无需手动删 | 但如果它属于别的账号，要先删 |

### 2.3 代码/参数按「2 并发」收紧

| 参数 | 建议值 | 理由 |
|---|---|---|
| `LLM_MAX_CONCURRENCY` | 2 | 硬上限 |
| 预取槽（`planner/scheduler.py`） | **最多 1 路在飞** | 1 路预取 + 1 路主决策 = 刚好 2 |
| `decide()` 的 `attempts` | 2（保持） | 但 `total_timeout` 要收紧，见下 |
| 决策总超时 | ≤ 40 s | 一次 300 token 决策 ≈ 12 s，重试一次 24 s；超过 40 s 说明后端异常，走规则兜底 |
| `MC_MODEL_TIMEOUT_S`（快路径单次） | 8 s | 已默认 |

> **如果最终确认只有 1 路并发**：关掉预取槽，`decide()` 必须串行等；把「确定性技能优先」从策略升级为硬规则（能不进模型的步骤都不进）。

## 4. 开赛前 60 秒自检（写进 `preflight.py`）

```
[ ] MC_API_BASE 指向正式端点（不是 127.0.0.1、不是 localhost）
[ ] MC_USER 是正式皮肤站角色名
[ ] LLM_KEY 不是群里那个压测 key（以 sk-mRbe 开头的是压测 key）
[ ] LLM_MODEL == "default"
[ ] LLM_MAX_CONCURRENCY <= 2
[ ] 8787 端口不通（网关已停）
[ ] 没有进程在跑 soak / 挂机脚本
[ ] .env 里没有把 MC_PROXY 填成 7897（除非确实需要走公网）
[ ] /status 的 RTT < 100ms（校园网应 ≈5ms；若 >500ms 说明走了公网）
```

**最后一条特别有用**：它一句话就能判断你现在连的是校园网还是公网。
