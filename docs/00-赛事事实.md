## Harness 赛道规则（公告原文口径）

- 统一模型：公告写 **DeepSeek V4.1 Flash**，走 AIA 统一代理 API；"不得改用其他大模型或通过外部服务绕开额度约束"。
- 参赛内容：自行设计 harness（规划调度、记忆、工具调用、状态维护、行为策略、多 Agent 协作），统一通过 NMO 接口操控。
- 赛中**允许**改提示词、调框架、重启程序；**禁止**参赛人员直接代替 Agent 执行游戏行为。
- 公告同时称："看重技术创意、游戏内自主行为、互动性与观赏性，不将单一任务完成率、固定模型基准作为唯一评判标准。"

## 初赛计分（细则口径）

- 总成绩 = **游戏表现分（60）+ 工程评审分（40）**，百分制，保留两位小数。
- 游戏表现分：只算**赛前公布的原版非配方 advancement**，每项一次。
  - ~~`单项分 = 难度基础分 + 5 × 进度树深度`~~ **【已作废 2026-11-13】v2 草案改为「分值只由难度决定」**
  - 难度 1/2/3/4/5 → 5 / 15 / 30 / 60 / 100；~~深度从各分类根节点分别起算~~ **【已作废】v2 草案：深度不计分**
  - v2 草案原文：「每项的分值**只由难度等级决定**」；5 个根节点为 0 分 `[RULES v2 草案]`
  - `游戏表现分 = 本人原始分 ÷ 本届最高原始分 × 60`（全员 0 则全 0）
- 工程评审分：≥3 名评委各 0–40，去一个最高一个最低取均值，保留两位。
  - 考察：设计完善性 / 方案技术新颖性 / 代码组织与实现逻辑清晰度 / 稳定性·可复现性·可维护性
- 平局：游戏表现分 → 难度 5 数量 → 难度 4 数量（逐级向下）→ 更早达到最终原始分 → 并列。
- 重点：**决赛计分方式"另行通知"**，截至 11/12 未发布。

## 比赛环境

- ~~每场一套独立生存世界；同场所有 Agent 共享同一世界~~ **【已作废 2026-11-13】** v2 草案改为**虚空岛**：每人一座**完全相同**的岛（同一世界截取的圆形区域，四周虚空），主世界与下界各一座，岛与岛相距很远、互不可见；只能在自己的岛及上下方活动 `[RULES v2 草案]`
- 末地**全服共用一座**；赛前主办方已击杀末影龙、开启折跃门、取走龙蛋；**禁止复活末影龙** `[RULES v2 草案]`
- 初赛、决赛各新建世界；赛前统一重置出生位置、背包、末影箱、经验、状态效果、advancement。
- 赛中因参赛程序/网络/模型服务造成的中断**仍计入时间，不补时**；仅赛事服务器统一故障才可能暂停/补时/重赛。
- 观众只能观察者身份；允许正常资源竞争与自愿协作；禁止漏洞、观众操控、人工代打、攻击基础设施、**持续性阻止其他 Agent 正常比赛**（PvP/破坏边界"NMO 提前公布"）。
- 服务器监控 + 世界快照（建议每 15–30 分钟）。

## 接口（规范 v1.3.1，2026-11-03）

- Base：`https://mc-api.windywindie.top/api/v1`（Cloudflare Tunnel）
- 认证：皮肤站账号 `/auth/login` 换 Bearer Token（皮肤站 https://skin.nmo.net.cn/，须先选定角色）
- **业务错误一律 HTTP 200**，看 `{ok, ms, result|error}`
- **动作互斥**：同一时间只能执行一个动作，重复调用返回 `busy`
- 决策粒度：**高层语义动作**（走到坐标 / 挖这个方块 / 合成这个物品），非模拟按键
- 明文限制：只返回**暴露方块**（无矿透）；不支持鞘翅飞行、逐 tick 键位控制；不提供自动反击
- 详见 `99-原始记录/api-spec-v1.3.1.md`
