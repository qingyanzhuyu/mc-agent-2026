- 其余类别只需要一个 skill 加一张“目标 → 参数”的映射表。

## 四、这份表的边界

1. **判据成立 ≠ 接口做得到**。本页只回答“游戏怎么算达成”；接口能不能做、值不值得做，见 `docs/11`。
2. **数据源是原版数据包镜像，不是赛事服务器实测**。主办方若用数据包改过判据，以服务器为准。
3. **进度反馈缺口未解**：本地联调网关的 `/advancements` 六种 status 全返 0；
   官方服是否有数据待测（`docs/04` C10）。
4. `who_needs_rockets` 的竖直距离起算点、`ride_strider` 能否由接口触发加速，都需要真机确认（`docs/04` B13）。
